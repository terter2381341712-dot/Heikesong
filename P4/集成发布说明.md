# zyc 集成候选版（契约 0.4.0，尚未发布）

本轮将冻结 origin/main 的工作台、连接码配对、权限、上传/下载、Windows 启动与共享控制，与 zyc 的常驻 CPU/GPU 执行器、容量槽位、资源感知调度和输入预取整合。main 引用保持不变；当前合并已解决冲突并暂存，尚未创建合并提交或阶段验收标签。

默认运行方式为 CPU 单槽、轮转策略、预取关闭。原工作台操作入口不增加计算设置页。新增 `P4/var/compute.json` 和 `--compute-config`，控制台与 CLI 共用校验；节点解释器独立于资源服务解释器。CPU 使用原 Python 3.9.6 环境，CUDA 显式选择独立 Python 3.11.9 环境并核验模型依赖。CUDA provider 不满足时拒绝准备。

三份 OpenAPI、P1/P2、任务类型、样例、前端版本检查、P4 健康/静态检查与 ZIP manifest 统一为 0.4.0。模型锁文件保留。JOIN/TASK/DEMO 权限边界与原 URL 保留；中心、节点、前端和工具必须同步升级。新增内部操作仍通过原节点 session/secret 或服务 Token 校验。

`round_robin` 保留新版容量与就绪检查，按节点轮转；显式 `resource_aware` 才使用性能排名与探索。CPU 多槽、预取、GPU 多路均显式配置。GPU 多路共享引擎锁，不能承诺并行推理提速；取消需确认线程 done，10 秒未完成时回收整进程并隔离所有路，可能中断同设备其他任务。已开始的取消握手不会因后续心跳不再返回取消 ID 而丢失。

已提供逐阶段 G0–G7 汇总、人工证据摘要验证、候选图片生成、三轮有效吞吐测量及同设备 CPU/GPU/池对比工具。质量参考未冻结则不产出“正确吞吐量”。数据升级检查只使用冻结 main 的停机测试副本，回滚恢复对应代码与数据，不能仅切旧代码读取新库。

当前本机证据见 [本轮报告](../qa/integration/README.md)。Windows NVIDIA、两位队友双机贡献、完整浏览器终态/下载、人工质量冻结与正式性能对照仍待完成；候选版不能标记为 S1–S7 正式通过，也不应部署覆盖日常数据。操作步骤、配置和回滚流程见 [集成验收](集成验收.md)。
