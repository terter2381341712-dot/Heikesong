# 现场演示（两次独立执行）

1. 由未写 P1/P2 模块的人按 P4 README 干净启动 A，再启动 B，记录 commit、契约/profile SHA、主机、网络和端口。沿用身份/令牌/数据，勿复制节点目录。演示开始核对两台真实独立设备。
2. 新拍摄或新制作有授权图片，至少20张不同内容，参考答案留在验收端。当前类型选择 OCR；ASR 显示未配置，不能伪装支持。
3. 先 health-only，再提交完整 verify，观察同一个 Job 的准备、等待、执行与结果；两台各至少一份有效结果，用 devices 映射核对。
4. 打开 results.json 与 ZIP，对照人工参考和输入顺序。记录用户等待时间与实际成功/失败项。API 客户端演示与 P3 浏览器演示分开；当前缺 P3，后者 NOT_RUN。
5. 用交互节点的 off/on 展示退出和恢复，提交新批次；保存资源变化、事件和 execution 链。活动工作关闭共享另作 I05/迁移实验，检查旧结果不能覆盖新结果。只做完两机不能签收三机 2→3→2→3 的 I04。
6. Ctrl+C 停止启动器后检查本次进程已退出，再按相同配置/目录重启，确认持久 Job、结果可查。X01/X02 的发送前/丢响应/汇总前等边界另按矩阵测试，不用普通重启替代全部场景。
7. 再运行一次，用新 out 和新图片集，保存报告。全部失败保留，缺项 NOT_RUN。演示者按缺陷模板记录复现，不修改数据库掩盖错误。

提交材料附设备授权、数据/模型来源许可、第三方和 AI 使用说明、成本估计。用户需求和商业反馈只有取得真实反馈才写成事实。任务包暂定截止为2026-11-15 12:00北京时间；此日期尚待核对主办方通知。
